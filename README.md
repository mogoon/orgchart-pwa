# 조직도 PWA (Org Chart PWA)

부서별 임직원 연락처를 관리하는 모바일 우선 PWA입니다. 서버 없이 정적 파일만으로 동작하며, 모든 데이터는 브라우저 `localStorage`에만 저장됩니다.

## 기능

- **조직도 보기** — 부서 → 팀 → 인원 3단계 구조, 접기/펼치기
- **통합 검색** — 이름 · 직급 · 팀 · 핸드폰(하이픈 유무 무관) · 내선 · 담당 업무 검색 + 하이라이트
- **편집 모드** (✏️) — 부서/멤버 추가·수정·삭제·순서 변경, 회사명 변경
- **엑셀 연동** — 조직도 전체를 `.xlsx`로 내보내기/불러오기 ([SheetJS](https://sheetjs.com/) 사용)
- **PWA** — 홈 화면 설치, 오프라인 동작 (서비스워커 캐싱)
- **전화 걸기** — 핸드폰 번호 탭 시 바로 전화 연결 (`tel:` 링크)

## 사용법

정적 호스팅(GitHub Pages 등)에 올리거나 로컬 서버로 실행합니다. 서비스워커 때문에 HTTPS 또는 `localhost`가 필요합니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

### 엑셀 형식

불러오기 시 첫 행 헤더를 다음과 같이 인식합니다 (표기 변형 허용: `부서`/`부서명`/`dept` 등):

| 부서 | 팀 | 이름 | 직급 | 핸드폰 | 내선번호 | 담당업무 |
|------|----|------|------|--------|----------|----------|
| 개발본부 | 서버팀 | 홍길동 | 과장 | 010-0000-0000 | 210 | 게임 서버 개발 |

`설정` 시트에 `회사명` 행을 두면 회사명도 함께 복원됩니다. (내보내기 파일이 이 형식 그대로이므로, 내보낸 파일을 수정해서 다시 불러오는 워크플로우를 권장합니다.)

## 데이터와 프라이버시

- 조직 데이터는 **브라우저 localStorage에만** 저장됩니다. 서버 전송 없음.
- 저장소에 포함된 인명·전화번호는 모두 **가상의 샘플 데이터**입니다.
- 실제 데이터로 내보낸 `.xlsx` 파일은 커밋하지 마세요 (`.gitignore`에 이미 차단되어 있음).

## 파일 구성

```
index.html            앱 전체 (HTML + CSS + JS 단일 파일)
manifest.webmanifest  PWA 매니페스트
service-worker.js     오프라인 캐싱
icon-*.png            앱 아이콘
```
